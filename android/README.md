# 峡谷 BP Android

原生 Android 悬浮助手。推荐算法已内置在 APK 中，英雄头像、巅峰千强梯度和四类英雄关系全部直连天元之弈国内接口，不经过公开 BP 站点。

## 数据与算法边界

### 1.8.0 更新

- 识别完成后，在悬浮窗点击“阵容对位分析”；手动 BP 页面也有同名入口。
- “五路对位”展示对抗、打野、中路、发育、游走；“组合联动”展示中野、中辅、边野、射辅的四项交叉克制和双方组合配合；“全对位”展示全部已录入英雄的交叉矩阵，可点击查看证据。
- 从两个英雄接口读取正负关系，反向克制方向翻转，配合方向保持对称；同一批对局不重复累加样本。推荐对小样本关系作收缩，不增加技能机制补正，也不展示算法权重。
- 分路先做全局可行分配，多位置英雄不会抢占单位置队友唯一可用的位置；无法分配的英雄保留为待分配，仍出现在全对位矩阵中。可手动换路、补录或清空英雄，不限制非常规位置。
- 缺失关系标注“暂无数据”，不能推断为均势。组合判断只代表已知交叉关系的方向，不是完整 2v2 对战胜率；敌方组合的正向配合意味着敌方配合良好。
- 增加 4:3、3:2、16:10、16:9、18:9、19.5:9、20:9、21:9、24:9 的边界适配，左右侧槽可独立小范围校准，单侧近黑导航边带可保守裁除。比例覆盖不等于所有 UI/皮肤都能准确识别。
- 相似度使用上界剪枝，不减少多尺度候选、不降低接受阈值。截帧使用实际 Image 尺寸，悬浮面板随可用屏幕大小调整。
- 对位页的阵容、分路和当前标签支持 Activity 重建恢复；关系请求最多并发四个，部分失败不伪造数据。

- 英雄与原始头像：`https://tianyuanzhiyi.com/api/allheroes`
- 巅峰千强梯度：`https://tianyuanzhiyi.com/api/global/tier?date=YYYY-MM-DD`，按中国日期请求，缺数时只回退最近两天。
- 克制、被克制、配合与不配合：`https://tianyuanzhiyi.com/api/hero/analysis?heroId=英雄ID`。
- 候选过滤、位置概率、梯度权重和四类关系计分全部由原生 `RecommendationEngine` 在手机本地执行。没有额外机制补正，也不需要打开或访问公开站点。

## 交互流程

### 手动自选

1. 在主页点击“打开手动 BP”。
2. 我方固定在左列、敌方固定在右列；点击五条分路对应的空位或头像，在三列英雄池中搜索、选择或替换英雄。多位置英雄会出现在其支持的每条分路中。
3. 通过独立 BAN 模块添加或移除已禁用英雄，并选择待补位置。
4. 点击“生成英雄推荐”；结果仅展示综合分与关系依据，不展示算法权重比例或置信度。
5. 推荐卡可直接“设为 BAN”“不想玩”或加入我方待补位置；不想使用的候选会被跳过，后续英雄按原评分顺位补上。

### 悬浮识别

1. 在应用中授权“显示在其他应用上层”。
2. 选择我方位于屏幕左侧或右侧，并选择待补位置。
3. 点击“启动悬浮助手”，在系统屏幕共享弹窗中确认。
4. 切回游戏，展开悬浮 BP 按钮并点击“识别两侧阵容与顶部 BAN 位”。
5. 悬浮窗隐藏后截取单帧，在设备内进行英雄头像识别；识别结果随后用于实时推荐。
6. 推荐生成后可对任意一位点击“不想玩”；该英雄会在本次识别中排除，后续候选按原评分顺位立即补上。重新识别新阵容时排除列表自动清空。

主页底部标注数据来源“天元之弈”、网址与作者邮箱；“觉得好用，就赞赏一下”会在应用内展示作者提供的微信收款码。

## 头像识别与版本更新

- 只生成左/右各 5 个已选槽和左上/右上各 5 个 BAN 槽，共 20 个识别框。中央英雄候选列表是硬排除区，不会进入识别。
- 不再从三套固定模板中硬选。识别前会用轻量头像特征连续搜索大头像列的横向锚点、裁剪尺寸、纵向偏移和纵向间距，再独立搜索顶部 BAN 行的起点、间距、高度与头像尺寸。
- BAN 行的起点会与已定位的大头像列保持游戏 UI 的相对几何约束，避免整行错开一格；最后再用完整多尺度描述做窄范围精调。中央候选区始终是硬排除区。
- APK 在软件启动时直连天元之弈原始英雄接口并为当前全部英雄生成多尺度、多水平/垂直偏移和圆形 BAN 裁剪变体。
- 头像缓存键为 `英雄 ID + avatarUrl 指纹`。上游版本更新导致 URL 变化时，只下载变化的头像并保留旧头像作为断网回退。
- 最高相似度、第一/第二候选分差和槽位对比度必须同时达标；空槽、陌生皮肤和不确定结果会跳过，不会强行猜英雄。
- 冷启动已移到应用进程启动阶段：实时元数据和头像描述库准备完成前，“启动悬浮助手”保持禁用，完成后同一进程内的识别直接复用内存头像库。
- 检测到左上角视频平台水印时，受遮挡的左侧 BAN 槽会整体忽略，避免把字幕或水印误识别成英雄；未遮挡的右侧 BAN 仍正常识别。

## 非标准阵容与多位置英雄

- 不要求敌我双方恰好五人；所有实际识别到的英雄都会进入关系计算。推荐中缺失关系不提供正负贡献，分析页明确显示“暂无数据”，不声称均势。
- 多位置英雄不会被强制判为唯一分路：有明确主分路时按主分路 0.6、其余位置均分 0.4；上游没有可靠主分路时按可用位置等概率处理。单位置英雄为 1.0。
- BAN、已选英雄和重复头像结果会去重并从候选中排除。
- OCR 只读取顶部的待选分路提示，不用英雄名称识别身份；读不到时保留用户手动选择。

## 隐私

截图只在用户点击悬浮按钮后获取一帧，并在设备内完成头像匹配。应用不上传截图；英雄、梯度与关系 JSON 仅直达 `tianyuanzhiyi.com`，头像图片使用该接口返回的国内 CDN 地址。

## 构建与安装

- Windows 下运行 `powershell -ExecutionPolicy Bypass -File .\build-apk.ps1`。
- 安装包输出到仓库根目录 `output\xia-gu-bp-polished-secure-v1.8.apk`。
- Release 产物启用 R8 代码混淆、优化与资源收缩，并使用项目本地独立密钥签名；这能提高反编译门槛，但不等同于不可破解的加密。
- 签名密钥与口令保存在被 Git 忽略的 `work\signing`。发布后必须单独备份该目录；丢失密钥将无法用同一签名覆盖升级已安装版本。
- 当前产物用于直接侧载；Android 8.0 及以上可安装。首次使用需要授权悬浮窗，并在系统弹窗中确认整个屏幕的录制权限。
