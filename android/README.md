# 峡谷 BP Android

原生 Android 悬浮助手，复用公开站点的巅峰千强实时接口与四因子推荐算法。

## 交互流程

1. 在应用中授权“显示在其他应用上层”。
2. 选择我方位于屏幕左侧或右侧，并选择待补位置。
3. 点击“启动悬浮助手”，在系统屏幕共享弹窗中确认。
4. 切回游戏，展开悬浮 BP 按钮并点击“识别当前阵容与 BAN 位”。
5. 悬浮窗隐藏后截取单帧，在设备内使用 ML Kit 中文模型 OCR；识别结果随后用于实时推荐。

## 非标准阵容与多位置英雄

- 不要求敌我双方恰好五人；所有实际识别到的英雄都会进入关系计算，缺失关系按中性值处理。
- 多位置英雄不会被强制判为唯一分路：有明确主分路时按主分路 0.6、其余位置均分 0.4；上游没有可靠主分路时按可用位置等概率处理。单位置英雄为 1.0。
- BAN、已选英雄和重复 OCR 结果会去重并从候选中排除。
- OCR 能读到明确分路文本时会自动切换，否则保留用户手动选择。

## 隐私

截图只在用户点击悬浮按钮后获取一帧，并在设备内完成 OCR。应用不上传截图；网络请求只用于获取站点的实时英雄、梯度与关系 JSON。

## 构建与安装

- Windows 下运行 `powershell -ExecutionPolicy Bypass -File .\build-apk.ps1`。
- 安装包输出到仓库根目录 `output\xia-gu-bp-ocr-overlay-v1.0.apk`。
- 当前产物用于直接侧载；Android 8.0 及以上可安装。首次使用需要授权悬浮窗，并在系统弹窗中确认整个屏幕的录制权限。
