# 峡谷 BP v1.8.0

支持 Android 8.0 及以上，沿用原签名，可覆盖安装 1.7.0。

## 新增阵容对位分析

- 识别完成后，点击悬浮窗里的“阵容对位分析”；手动 BP 页面也提供入口。
- 查看对抗、打野、中路、发育、游走五条路的对位优劣。
- 查看中野、中辅、边野、射辅的交叉克制，以及敌我双方的正负配合。
- 全对位矩阵覆盖全部已录入英雄，可点击查看指数及样本量。
- 支持多位置英雄的全局分路推断、手动换路与补录。无法分配的英雄不会被强塞进常规阵容。
- 缺失关系明确标注“暂无数据”，不当作均势；组合指数不是实际 2v2 胜率。分路校正仅作用于分析页。

## 识别与推荐优化

- 增加平板、超宽横屏、左右独立边距与单侧黑边适配。
- BAN 行采用整行校准、同侧重复猜测去重和清晰头像优先，减少偏移误识别。
- 相似度上界剪枝减少计算，不减少候选、不降低识别接受阈值。
- 正负克制和配合使用统一的双向关系读取，并对小样本作收缩；不添加技能机制补正，不展示算法权重。
- 关系请求最多并发四个，部分请求失败不伪造数据；改善横屏布局及页面旋转恢复。

## 测试与使用提醒

- 23 项单元测试通过，正式签名包完成 1.7.0 → 1.8.0 覆盖安装验证。
- 同一 BP 截图生成的 10 个比例／边距变体，已选及 BAN 英雄集合均通过回归。它们不是 10 台真机或独立对局；新皮肤、遮挡与游戏 UI 更新仍需实际验证。
- 英雄、梯度与关系数据直连天元之弈；截图识别和推荐计分在设备本地进行。
