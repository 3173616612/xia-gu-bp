# 峡谷 BP v1.9.0 · 全新界面

支持 Android 8.0 及以上，沿用原包名与正式签名，可覆盖安装 1.8.0。

## 界面与交互更新

- 更新主页、手动 BP、英雄选将面板、推荐卡、五路对位、组合联动及完整对位矩阵。
- 四列英雄池支持名字、拼音和拼音首字母搜索（拼音搜索需 Android 10 及以上），保留分路筛选和真实英雄头像。
- 手动 BP 保持我方在左、敌方在右，阵容、BAN 位或待补位置改变后自动更新推荐；支持“不想玩”顺位递补及直接选入阵容。
- 悬浮面板支持拖动，切换分路或敌我方向即可重新计算推荐。
- 修复悬浮面板展开时从竖屏切到横屏后，底部“识别 BP 画面”按钮落到屏幕之外的问题。

## 验证

- 23 项单元测试通过，Debug 和正式签名 Release 包构建通过；正式包启用 R8 混淆、资源收缩。
- 在 Android 11 模拟器检查选将、拼音首字母搜索、自动推荐、跳过英雄、对位分析、证据弹窗及悬浮窗横竖屏切换。
- 完成正式包从 1.8.0 到 1.9.0 的覆盖安装验证。
- 本次未修改头像识别核心；界面与模拟器检查不代表所有皮肤、设备和游戏版本均已实测。

详细记录：[QA-1.9.0.md](https://github.com/3173616612/xia-gu-bp/blob/v1.9.0/android/QA-1.9.0.md)。
